# QMT 文件下单协议

本文档整理 QMT 文件下单的输入文件格式、字段顺序和字段枚举。当前推荐使用
`CSV 预埋单`作为外部系统到 QMT 的批量下单协议。

注意：QMT 文档中的 `position*.csv` 是 QMT 导出的持仓回报文件，不是下单输入文件。
外部系统给 QMT 下单时，应写入 `signal...txt` 报单文件。


QMT 启动监控后，会扫描该目录下符合格式的 `TXT` 下单文件，并同步导出委托、成交、
持仓、资金等回报文件。

当前实盘配置建议拆成两个目录：

```text
C:\quant\place      # CSV 预埋单监控目录，系统上传 signal.*.txt
C:\quant\position   # QMT 数据导出目录，系统读取持仓/资金/委托/成交
```

对应 K8s 环境变量：

```text
QMT_ORDER_REMOTE_DIR=C:\\quant\\place
QMT_EXPORT_REMOTE_DIR=C:\\quant\\position
```

### 1.2 输入文件名

报单/撤单文件名：

```text
signal.{资金账号}_{账号类型}.{下单文件序号}.txt
```

也支持带日期格式：

```text
signal.{资金账号}_{账号类型}.{下单文件序号}.{YYYYMMDD}.txt
```

使用带日期格式时，日期必须为当天，否则 QMT 不执行。下单文件序号自定义且不可重复，
建议使用数字时间戳。

示例：

```text
signal.88888888_2.20260606093500.txt
signal.88888888_2.20260606093500.20260606.txt
```

### 1.3 账号类型

| 值 | 含义 |
|---:|---|
| 1 | 期货 |
| 2 | 股票 |
| 3 | 信用 |
| 7 | 沪港通 |
| 11 | 深港通 |

普通股票账号使用 `2`。

### 1.4 报单文件内容

文件内容为英文逗号分隔文本。无表头，每行一条委托。

字段顺序固定：

```text
投资备注,报单类型,报价方式,报单价格,证券代码,下单总量,策略名称
```

字段说明：

| 顺序 | 字段 | 类型 | 必填 | 示例 | 说明 |
|---:|---|---|---|---|---|
| 1 | 投资备注 | String | 是 | `model_a_20260606093500` | 自定义备注，委托/成交回报中原样返回 |
| 2 | 报单类型 | String | 是 | `23` | 买卖、两融、期货或撤单类型 |
| 3 | 报价方式 | String | 是 | `1` | 最新价、指定价、市价方式等 |
| 4 | 报单价格 | String | 是 | `0` | 最新价填 `0`；指定价填实际价格 |
| 5 | 证券代码 | String | 是 | `SH600000` | 市场代码 + 证券代码 |
| 6 | 下单总量 | String | 是 | `1000` | 股票单位为股，普通 A 股通常为 100 股整数倍 |
| 7 | 策略名称 | String | 是 | `model_a` | 自定义策略名称 |

示例：最新价买卖。

```csv
model_a_20260606093500,23,1,0,SH600000,1000,model_a
model_a_20260606093500,24,1,0,SZ000001,500,model_a
```

示例：指定价买卖。

```csv
model_a_20260606093600,23,3,12.34,SH600000,1000,model_a
model_a_20260606093600,24,3,9.87,SZ000001,500,model_a
```

### 1.5 证券代码格式

CSV 预埋单要求证券代码为“市场代码 + 证券代码”：

| 内部代码 | QMT 代码 |
|---|---|
| `600000.SH` | `SH600000` |
| `000001.SZ` | `SZ000001` |

### 1.6 报单类型枚举

股票 / 两融：

| 值 | 含义 |
|---:|---|
| 23 | 证券买入 / 担保品买入 |
| 24 | 证券卖出 / 担保品卖出 |
| 27 | 融资买入 |
| 28 | 融资卖出 |
| 29 | 买券还券 |
| 30 | 直接还券 |
| 31 | 卖券还款 |
| 32 | 直接还款 |

期货：

| 值 | 含义 |
|---:|---|
| 0 | 开多 |
| 1 | 平昨多 |
| 2 | 平今多 |
| 3 | 开空 |
| 4 | 平昨空 |
| 5 | 平今空 |
| 6 | 平多，优先平今 |
| 7 | 平多，优先平昨 |
| 8 | 平空，优先平今 |
| 9 | 平空，优先平昨 |
| 10 | 卖出，如有多仓优先平今，余量开空 |
| 11 | 卖出，如有多仓优先平昨，余量开空 |
| 12 | 买入，如有空仓优先平今，余量开多 |
| 13 | 买入，如有空仓优先平昨，余量开多 |
| 14 | 买入，不优先平仓 |
| 15 | 卖出，不优先平仓 |
| 16 | 开 |
| 17 | 平，优先平昨 |
| 18 | 平，优先平今 |
| 19 | 看多，优先平昨 |
| 20 | 看多，优先平今 |
| 21 | 看空，优先平昨 |
| 22 | 看空，优先平今 |

普通股票交易只需要使用：

```text
23 买入
24 卖出
```

### 1.7 报价方式枚举

CSV 预埋单使用以下报价方式。不要与便捷交易的报价代码混用。

| 值 | 含义 |
|---|---|
| 1 | 最新价 |
| 3 | 指定价 |
| 6 | 科创盘后定价 |
| M1 | 最优五档即成剩撤，SH |
| M2 | 最优五档即成剩转，SH |
| M3 | 即时成交剩余撤销委托，SZ |
| M4 | 全额成交或撤，SZ |
| M5 | 本方最优价，SZ |
| M6 | 对手最优价，SZ |
| M7 | 最优五档即时成交剩余撤销委托，SZ |

第一版建议使用：

```text
1 最新价
```

指定价使用：

```text
3 指定价
```

### 1.7.1 引擎输出到 QMT adapter 的字段

实盘引擎不会把 `position` 权重直接推给 QMT。只有推理模块返回明确订单字段时，
才会生成 QMT `signal.*.txt` 文件。

最小字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| `code` | 是 | 内部代码，如 `600000.SH` 或 `000001.SZ` |
| `side` | 是 | `buy`/`sell`，也支持 `买入`/`卖出` |
| `volume` | 是 | 下单股数 |

可选字段：

| 字段 | 说明 |
|------|------|
| `price_type` | `latest`/`market` 映射为 `1`；`limit` 映射为 `3`；也可直接填 `1`/`3`/`M1` 等 |
| `limit_price` | 指定价，`price_type=3` 时使用 |
| `strategy` | 策略名称，缺省使用 `QMT_STRATEGY_NAME` |
| `note` / `remark` | 投资备注 |
| `qmt_order_type` | 直接指定 QMT 报单类型，例如 `23`/`24` |
| `qmt_price_type` | 直接指定 QMT 报价方式 |
| `qmt_price` | 直接指定 QMT 报单价格 |
| `qmt_volume` | 直接指定 QMT 下单总量 |

示例：

```csv
code,side,volume,price_type,limit_price,strategy,note
600000.SH,buy,1000,latest,0,model_a,model_a_20260607093500
000001.SZ,sell,500,limit,9.87,model_a,model_a_20260607093500
```

### 1.8 撤单文件内容

撤单文件名仍然使用：

```text
signal.{资金账号}_{账号类型}.{下单文件序号}.txt
```

字段顺序固定：

```text
报单类型,撤单编号,市场
```

字段说明：

| 顺序 | 字段 | 类型 | 必填 | 示例 | 说明 |
|---:|---|---|---|---|---|
| 1 | 报单类型 | String | 是 | `cancel_sys` | `cancel_sys` 使用合同编号撤单；`cancel_id` 使用订单编号撤单 |
| 2 | 撤单编号 | String | 是 | `ABC123456` | 合同编号或订单编号 |
| 3 | 市场 | String | 是 | `SH` | `SH`、`SZ`、`SGT`、`HGT` |

示例：

```csv
cancel_sys,ABC123456,SH
cancel_id,987654321,SZ
```

### 1.9 QMT 回报文件

QMT 监控目录下会生成以下回报文件：

```text
order.{账号}_{账号类型}.{日期}.csv
order_error.{账号}_{账号类型}.{日期}.csv
cancel_error.{账号}_{账号类型}.{日期}.csv
deal.{账号}_{账号类型}.{日期}.csv
position.{账号}_{账号类型}.{日期}.csv
asset.{账号}_{账号类型}.{日期}.csv
signal_backup\
```

这些是 QMT 输出文件，用于读取委托、成交、持仓和资金状态。不要把它们当作下单输入。
